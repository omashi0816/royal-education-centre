## Getting Started

### First Login

1. Open your browser and navigate to the system URL
2. Enter your username and password
3. Click "Sign In"
4. You will be redirected to your role-specific dashboard

### Navigation

- **Sidebar** — Main navigation menu (click hamburger icon on mobile)
- **Top Bar** — Search, user menu, notifications
- **Dashboard** — Overview with statistics and recent activity

### Changing Password

1. Click on your name in the top right
2. Select "My Profile"
3. Scroll to "Change Password" section
4. Enter current password
5. Enter new password (minimum 6 characters)
6. Click "Save Changes"

### Logging Out

1. Click on your name in the top right
2. Select "Logout"

## Administrator Guide

### Dashboard Overview

The admin dashboard displays:
- Total students, teachers, staff count
- Active courses and batches
- Total revenue and monthly income
- Recent payments and upcoming exams
- Recent activity logs
- Recent notices

### User Management

#### Creating a New User

1. Go to **Users** → **Add User**
2. Select the role (Admin, Manager, Teacher, Student, Receptionist, Cashier)
3. Enter username, email, password
4. Enter full name and phone
5. Set status to Active
6. Click "Save User"

#### Managing Users

- **Edit** — Click edit icon to modify user details
- **Toggle Status** — Click power icon to activate/deactivate
- **Delete** — Click trash icon to delete (cannot delete your own account)

### Student Management

1. Go to **Students**
2. View all students with their codes and status
3. Click edit icon to modify student profile
4. Click eye icon to view detailed profile

### Teacher Management

1. Go to **Teachers**
2. View all teachers with their specialization
3. Click edit icon to modify teacher details
4. Click eye icon to view detailed profile

### Course Management

1. Go to **Courses**
2. View all courses with subject count and status
3. Filter by status (Pending, Approved, Active, etc.)
4. Click edit to modify course details

### Batch Management

1. Go to **Batches**
2. View all batches with course information
3. Filter by status
4. Click edit to modify batch details

### Payment Management

1. Go to **Payments**
2. Filter by status and date range
3. View all payment records with student details
4. Receipt numbers are displayed for completed payments

### Activity Logs

1. Go to **Activity Logs**
2. View all system actions with timestamps
3. See which user performed each action
4. Filter by action or module

The receptionist dashboard displays:

- Pending inquiries
- Today's registrations

2. Enter personal information

## Cashier Guide

### Dashboard Overview

The cashier dashboard shows:
- Today's collection
- Month collection
- Due payments
- Today's transactions

### Collect Payment

1. Go to **Collect Payment**
2. Select student
3. Select payment type (Registration, Course Fee, Monthly Fee, etc.)
4. Enter amount
5. Apply discount if applicable
6. Select payment method (Cash, Online, Bank Transfer)
7. Click "Collect Payment"
8. Note the receipt number

### All Payments

1. Go to **All Payments**
2. View all payment records
3. Filter by status and date
4. View receipt numbers

### Due Payments

1. Go to **Due Payments**
2. View students with pending payments
3. See due amounts

## Common Tasks

### Forgot Password

If you forget your password, contact the administrator to reset it.

### Profile Update

1. Click your name in top right
2. Select "My Profile"
3. Update your information
4. Click "Save Changes"

### Viewing Notices

Notices appear on your dashboard. Pinned notices are displayed at the top.

### Searching

Use the search bar in the top navigation to search across the system.

### Exporting Reports

Most report pages have export options to download as PDF or Excel.

### Printing

Use your browser's print function (Ctrl+P) to print any page or report.
